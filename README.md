# WordBlast
A Java based Word Game where players have to input words based off randomly generated connected characters

## Features

- Validates player entered English words
- Uses a local words.txt dictionary
- Rejects words that have already been used
- Generates valid connected characters that

## How it Works
1. The game will generate a sequence of starting letters
2. Players will enter a word that contains those connected characters
3. The game will then check if that word
    - If the word contains the required characters
    - Has already been used
    - If it is a valid word
4. A valid word will give the player points and remove it from the available word collection
5. The game will loop and create a new sequence of characters
